# Mygir

Стартап-проект в нише **фриланс / малый бизнес**. Цель — продукт, который легко
продать, реализуем небольшой командой и монетизируется по модели **freemium**.

## Текущий этап: анализ рынка

Сначала изучаем рынок и выбираем продукт, затем строим MVP.

- 📊 [Анализ рынка](docs/market-analysis.md) — тренды, конкуренты, боли, SEO,
  сравнение вариантов и рекомендация.
- 🧾 [Спецификация MVP](docs/mvp-spec.md) — бесплатный генератор счетов в браузере.

## Краткий вывод

Рекомендованный MVP — **по-настоящему бесплатный, приватный генератор счетов**,
работающий целиком в браузере (без сервера, без рекламы, без водяных знаков).
Канал привлечения — органический поиск (`free invoice generator`, ~50K запросов/мес).
Платный план (позже): сохранённые клиенты, брендированные шаблоны, повторяющиеся
счета и авто-напоминания о просрочке.
