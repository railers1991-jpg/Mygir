# Mygir

Бесплатный генератор счетов и смет для фрилансеров и малого бизнеса.
Работает в браузере, без рекламы и водяных знаков. Опционально — облачные
аккаунты с регистрацией, входом и базой данных (Supabase).

**Демо:** https://railers1991-jpg.github.io/Mygir/

## Возможности

- Счета и сметы (КП), статусы (черновик / не оплачен / оплачен, штамп «ОПЛАЧЕНО»).
- 3 шаблона дизайна (Modern / Classic / Minimal), свой цвет и логотип.
- Налог по каждой позиции, скидки, 9 валют (форматирование через `Intl`).
- История документов и клиенты, авто-номер счёта.
- Языки EN/RU, светлая/тёмная тема, экспорт/импорт данных (JSON).
- Экспорт в PDF, печать. Гостевой режим — данные в браузере (localStorage).

## Облачные аккаунты (опционально)

Без настройки приложение работает офлайн (данные только в браузере).
Чтобы включить регистрацию, вход и несколько фирм на аккаунт:

1. Создай бесплатный проект на https://supabase.com
2. SQL Editor → вставь содержимое [`supabase/schema.sql`](supabase/schema.sql) → Run
3. Project Settings → API → скопируй **Project URL** и ключ **anon public**
4. Вставь их в [`js/supabase-config.js`](js/supabase-config.js) вместо `YOUR_...`
5. Закоммить и задеплой — появятся вход/регистрация и вкладка «Фирмы».

Ключ `anon` безопасно держать в коде фронтенда: данные защищает
Row Level Security в БД (см. `supabase/schema.sql`) — пользователь видит только своё.

## Структура

- `index.html`, `css/styles.css` — интерфейс.
- `js/i18n.js` — переводы EN/RU.
- `js/store.js` — локальное хранилище (гостевой режим).
- `js/cloud.js`, `js/supabase-config.js` — облачный слой (auth + БД).
- `supabase/schema.sql` — схема базы данных с RLS.
- `docs/` — анализ рынка и спецификация.
