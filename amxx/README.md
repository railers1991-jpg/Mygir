# Mygir — свои плагины для CS 1.6 на Pawn (AMX Mod X)

Набор **наших собственных** игровых плагинов для настоящего сервера
Counter-Strike 1.6. Геймплей пишется на Pawn и работает поверх движка запуска
**AMX Mod X** — сам AMX геймплей не задаёт, это «загрузчик»; всё, что в папке
`scripting/`, — наш код.

> Альтернатива на чистом C++ (без AMX) лежит в `../forge` — это отдельная
> опция «всё своё на нативе». Здесь — быстрый и дружелюбный к доработке путь.

## Что внутри

| Плагин | Файл | Что делает |
|--------|------|------------|
| **Classic+** | `mygir_classicplus.sma` | Флагман: перки на жизнь (`/perk`), First Blood, бонус за хедшот, **Bounty / Most Wanted** (серия убийств подсвечивает игрока, за его голову платят), Adrenaline (хил за клатч-килл) |
| **Ranks** | `mygir_ranks.sma` | XP за убийства/победы, уровни и звания, прогресс сохраняется между картами (`nvault`). Команды `/rank`, `/top` |
| **Shop** | `mygir_shop.sma` | Магазин доп. снаряги за внутриигровые деньги — `/shop` |

Общие хелперы (цветной чат, выдача денег, проверки) вынесены в
`scripting/include/mygir.inc`.

## Команды для игроков

| Команда | Действие |
|---------|----------|
| `/perk` | выбрать перк (применится со следующего спавна) |
| `/shop` | открыть магазин |
| `/rank` | показать своё звание и прогресс |
| `/top`  | топ онлайна по уровню |

## Требования

- Сервер **CS 1.6** (HLDS или ReHLDS) с установленными **Metamod** и **AMX Mod X 1.9+**
- Модули AMX Mod X: `cstrike`, `fun`, `hamsandwich`, `fakemeta`, `nvault`
  (все идут в стандартной поставке — проверь, что включены в
  `addons/amxmodx/configs/modules.ini`)

## Сборка плагинов

Pawn-исходники компилируются в `.amxx` компилятором AMX Mod X (`amxxpc`).

### Вариант A — локально

```bash
# из поставки AMX Mod X положи рядом amxxpc и папку include/
cd amxx/scripting

amxxpc mygir_classicplus.sma
amxxpc mygir_ranks.sma
amxxpc mygir_shop.sma
# => получаются *.amxx
```

Компилятору нужно видеть наш `include/mygir.inc`. Он лежит в
`scripting/include/`, который `amxxpc` подхватывает автоматически.

### Вариант B — веб-компилятор

Любой онлайн-компилятор AMX Mod X: загрузи `.sma` + `mygir.inc`.

## Установка на сервер

1. Скопируй скомпилированные файлы:
   ```
   *.amxx            -> addons/amxmodx/plugins/
   ```
2. Добавь плагины в `addons/amxmodx/configs/plugins.ini`
   (готовый список — `configs/plugins-mygir.ini`):
   ```
   mygir_classicplus.amxx
   mygir_ranks.amxx
   mygir_shop.amxx
   ```
3. Скопируй конфиг:
   ```
   configs/mygir.cfg -> addons/amxmodx/configs/mygir.cfg
   ```
   и подключи его в `server.cfg`:
   ```
   exec addons/amxmodx/configs/mygir.cfg
   ```
4. Перезапусти сервер (или `amxx reload` для горячей перезагрузки плагина).

## Настройка

Все параметры — cvar'ы в `configs/mygir.cfg` (бонусы, пороги серий, цены перков,
кривая XP). Меняешь значение — перечитываешь конфиг, перезапуск не нужен.
